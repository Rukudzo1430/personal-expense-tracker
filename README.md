# personal expense tracker
A python application for tracking expenses and analysing spending
Personal Expense Tracker

## About the Project
The Personal Expense Tracker is a beginner-friendly Python application that helps users record and analyse their personal expenses.

## Features
- Add new expenses
- Categorise expenses
- Save expense records in a CSV file
- Calculate total expenses
- Calculate spending by category
- Identify the highest-spending category
- Validate expense names and amounts

## Technologies Used
- Python
- CSV file handling
- GitHub

personal-expense-tracker/

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the command:

   python main.py
